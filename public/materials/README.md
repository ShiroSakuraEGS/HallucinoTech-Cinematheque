# 致幻技電影館 · 素材資料夾說明指南

親愛的創作者 **白櫻蒼成**，這裡是專門為您建立的圖像與文本素材資料夾。
您可以直接將您製作的檔案放置在對應的資料夾中，應用程式會自動偵測並載入！

---

## 📁 資料夾結構

```text
/public/materials/
├── images/
│   ├── characters/              # 角色立繪圖像
│   │   ├── clerk.png            # 店員揭曉真容立繪（雌雄同體的可愛外表）
│   │   └── clerk_blush.png      # （選填）店員臉紅/心動差分表情
│   │
│   ├── posters/                 # 四套電影專屬海報
│   │   ├── xibuxi.png           # 《囍不喜》海報
│   │   ├── dianziqian.png       # 《電子籤》海報
│   │   ├── fenweibiancheng.png  # 《氛圍編程》海報
│   │   └── qingrenguan.png      # 《情人館》海報
│   │
│   └── scenes/                  # （選填）場景背景圖
│       ├── facade.png           # 電影館門面
│       ├── counter.png          # 昏暗櫃檯
│       └── theater.png          # 放映廳與銀幕
│
└── texts/
    ├── dialogues.json           # 完整對話劇本設定檔（已為您建立模板）
    └── custom_notes.txt         # 創作備忘錄
```

---

## 📝 文本修改指南（`texts/dialogues.json`）
您可直接編輯 `texts/dialogues.json` 中的句子，包括：
- 店員問候與對白
- 四套電影的觀影心得與身旁耳語對白
- 電影結束後的驚豔心動獨白
- 謝幕演職員名單

---

## 🖼️ 圖像上傳與使用方式
1. **直接置放**：將圖片重命名為上述檔名（如 `clerk.png`、`xibuxi.png`）放入資料夾。
2. **網頁介面上傳**：亦可隨時在遊戲畫面右上角點擊「素材自訂（滑桿圖標）」透過檔案選取器上傳預覽。
